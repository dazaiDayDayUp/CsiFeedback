# CylinderCodec：几何正确的角度-时延反馈网络

> 分支 `idea/cylinder_codec`。base commit `68ffcc1`。

## 1. 动机：三次参数化物理建模的失败

本 idea 之前尝试了三条「用传播几何参数化 CSI」的路线，全部失败，结论一并记录在此，
因为它们决定了本 idea 的设计方向。

### 1.1 数据侧的定量事实（`CsiFeedback-research/analysis/`）

都在 COST2100 indoor 全 20000 测试样本上、用与 `compute_nmse` 完全一致的约定
（实部虚部都减 0.5，`10log10(mean(||err||²/||h||²))`）测得。

| 预算（实数） | PCA | 低秩+全因子 | top-k 稀疏（位置免费） | 谐波子空间 | STNet |
|---|---|---|---|---|---|
| 512 (CR1/4) | -29.2 | -26.4 (r=4) | -27.3 | — | **-30.2** |
| 256 (CR1/8) | -13.8 | -15.7 (r=2) | **-21.0** | -2.4 | -19.3 |
| 128 (CR1/16) | -8.8 | -9.7 (r=1) | **-16.3** | -1.9 | -14.8 |
| 64 (CR1/32) | -5.1 | — | **-12.6** | -0.9 | -9.5 |
| 32 (CR1/64) | -3.0 | — | **-9.5** | -0.4 | -6.8 |

关键读数：

- **CR=1/4 已接近饱和**：STNet -30.2 只比 512 维全局线性子空间（PCA -29.2）好 1 dB，
  比每样本自由基秩 4（-26.4）还好。低压缩比下没有可观的非线性 headroom。
- **高压缩比才有空间**：CR=1/8 到 1/64，STNet 比 PCA 好 4-6 dB，但仍比
  「自由位置的 top-k 稀疏 oracle」差 1.5-3 dB。这是唯一稳定的结构性 gap。
- **紧凑参数族全部失效**：
  - 单径 Dirichlet 原子（3 参数，角度 N=32 / 时延 N=125 截断）最优单原子只有
    **-0.34 dB**（自由基秩 1 是 -9.7 dB）；
  - 谐波子空间码本（奇异因子截断到 m 个谐波）r=1,m=16 只有 -2.44 dB；
  - 2D 高斯团块（6 参数）k=4 只有 -5.16 dB，同预算自由稀疏系数约 -8 dB。
- 支撑结构：99% 能量所需系数 k99 均值 105（强样本 163、弱样本 52）；时延轴 92%
  能量在前 4 个 tap 且单调衰减；角度轴能量集中在 broadside 扇区，且在 bin 30/31
  明显回绕（0.026/0.037），证明**角度轴是圆周**。

结论：COST2100 indoor 的角时延域能量是**弥散**的，不存在可压缩的紧凑几何参数族；
把物理先验写成「几个路径/簇的参数」在这份数据上系统性失效（这也解释了
`path_geometry_feedback` 的 -20.4 dB 与 `angle_delay_equivariant` 的 -24.4 dB）。

### 1.2 仍然成立的物理事实

1. **角度轴是圆周**：均匀线阵的阵列流形以 1 为周期，32 点 DFT 的角度 bin 首尾相接。
   零填充在 bin 0/31 处制造了物理上不存在的「墙」。
2. **时延轴是半直线**：时延非负，tap 0 是首达径，左侧没有负时延；右侧是截断。
3. **报告指标是逐用户归一化的**：`mean_i(||err_i||²/||gt_i||²)`，与 baseline 训练用的
   逐元素 MSE 对样本的加权完全不同（MSE 按功率加权，NMSE 等权并动态聚焦高误差样本）。

## 2. 方法

### 2.1 几何正确的卷积算子

`CylindricalConv2d`：角度轴用圆周（周期）填充，时延轴用零（吸收）填充。这是对
表示流形几何的**硬约束**，不引入任何参数，也不改变 baseline。

### 2.2 各向异性残差块

`CylBlock`：角度方向 5×1 卷积（波束方向的连续性） → 时延方向 1×5 卷积（功率时延谱的
局部性） → SE 通道注意力 → 残差。膨胀率按 1,1,2,2,4,4,8,8 递增，最大感受野覆盖整个
角度圆周与整条时延轴。

### 2.3 目标对齐

`MetricMSELoss = mean_i(||pred_i-gt_i||²/||gt_i-0.5||²)`，与 `compute_nmse` 只差一个
`log10`。训练目标与报告指标完全一致；`select_best: val_loss` 时验证集也用同一目标，
因此 checkpoint 选择与部署指标一致，且完全不使用测试集。

### 2.4 结构

```
encoder: stem(2→64, circ 3×3) → 8×CylBlock(64) → LN → 1×1(64→16) → 1×1(16→2)
         → flatten(2048) → Linear(2048→encoded_dim)
decoder: Linear(encoded_dim→2048) → 2×32×32 → stem(2→64) → 8×CylBlock(64)
         → LN → 1×1(64→16) → 1×1(16→2) → +0.5
```

CR1/4 时 2.78M 参数（STNet CR1/4 有效参数约 2.12M，记录值 3.18M 含未使用的 `fc`）。

## 5. 风险与判据

- 若 CR1/4 的 300 epoch screen 明显落后 STNet 同期（STNet 300 epoch = -26.67），
  说明主干容量/配方不足，需要调整深度/宽度/学习率后再试，而不是直接跑 1000 epoch。
- 若 metric loss 让训练不稳定（ratio 长尾导致梯度爆炸），退回 MSE + metric 混合。
- 若 CR1/64 的相对增益显著大于 CR1/4（预期），则论文叙事成立：「物理几何约束 +
  指标对齐在高压缩比下收益最大」。
